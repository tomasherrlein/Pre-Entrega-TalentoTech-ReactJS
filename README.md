# TalentoLab — E-commerce (Pre-Entrega React JS)

Tienda online hecha con React + Vite. Catálogo desde JSON local, ruteo con react-router-dom y carrito con Context API.

## Rutas

| Ruta | Descripción |
|------|-------------|
| `/` | Inicio: bienvenida + productos destacados |
| `/productos` | Catálogo completo |
| `/producto/:id` | Detalle de un producto + agregar al carrito |
| `/carrito` | Carrito: cantidades, eliminar item y total |

## Correr en local

```bash
npm install
npm run dev
```

## Tecnologías

React · Vite · React Router · Context API · CSS Modules
